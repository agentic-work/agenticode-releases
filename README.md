# agenticode

Signed release binaries for agenticode. **This repository holds compiled downloads only. agenticode is proprietary, closed-source software; no source code is published here.**

## Install the terminal app

macOS and Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/agentic-work/agenticode-releases/main/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/agentic-work/agenticode-releases/main/install.ps1 | iex
```

Update any time with `agenticode update`.

## Desktop app

Download the macOS DMG or Windows setup from [Releases](https://github.com/agentic-work/agenticode-releases/releases/latest).

Every release lists SHA-256 checksums in `checksums.txt`, and the installers verify them.
